# Plan de pruebas OFTAR

- **Fecha:** 2026-11-28
- **Versión:** 1.0
- **Documento rector:** `especificacion-definitiva-reconstruccion-oftar.md` v1.0
- **Estado:** `OFTAR v1.0 — Especificación técnica consolidada, con modelo integral de relaciones clínicas y terminológicas, preparada para iniciar la implementación controlada. (No autoriza ejecución.)`
- **Convención:** `[H]` hecho verificado · `[I]` inferencia · `[P]` propuesta/plan sujeto a aprobación o acta.

> **Alcance documental.** Este plan define pruebas de verificación para OFTAR-PR y OFTAR-DX. No autoriza ejecución en producción, seeds, migraciones, importaciones, publicación ni aprobaciones clínicas. Toda prueba que implique base de datos, API viva o tests PHP requiere acta, entorno controlado y autorización explícita.

## 1. Regla crítica de evidencia

| Sección/columna | Significado | Estado permitido en esta ronda |
|---|---|---|
| `Revisado en esta ronda` | Solo lectura de código, SQL o documentación. No implica ejecución. | Puede marcarse como `Sí (lectura)` o describir el artefacto leído. |
| `Ejecutable cuando haya acta/entorno` | Prueba SQL de solo lectura, test PHP o verificación de API ejecutable solo tras acta, entorno y autorización. | Describe el comando/consulta prevista; no afirma ejecución. |
| `Resultado` | Resultado observado por ejecución real. | **PENDIENTE** salvo evidencia de ejecución adjunta en acta separada. |

**No se afirma que una prueba fue ejecutada si solo se revisó su código.**

**Antecedente histórico (no ejecutado en esta ronda):** en una ronda anterior `php tests/run.php` registró `OK: 4068 comprobaciones`. En esta ronda **NO** se ejecutó `php tests/run.php`, ni SQL, ni seeds, ni migraciones.
